# MI-BAK-Repack
Reempacotador de backups da xiaomi(.bak).

> [!WARNING]  
> **Status do Projeto:** Atualmente desatualizado / Não funcional para bypass em versões recentes da MIUI / HyperOS (Android 13+).
> 
> O script é totalmente capaz de desempacotar, modificar e recriar arquivos `.bak` mantendo a estrutura do cabeçalho oficial da Xiaomi e os blocos TAR. No entanto, devido às validações de integridade do sistema do Android Backup Manager e à gestão restrita de UID/GID em aparelhos mais recentes, os dados injetados podem não ser reconhecidos pelos aplicativos após a restauração.
>
> *Este repositório é mantido principalmente para fins educacionais e como documentação da estrutura do cabeçalho binário `.bak` da Xiaomi.*
